# Security

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/imkeuri/ferry-umbraco/security/advisories/new),
not in a public issue or discussion.

Include the Ferry and Umbraco versions, what an attacker can do, and how to reproduce it. Remove real tokens,
connection strings and passwords. You will get a reply within a few working days.

Only the latest Ferry release receives security fixes.
